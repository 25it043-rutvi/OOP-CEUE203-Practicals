# Practical 12 — Part A

This folder contains the Part A practice programs from the CEUE203 practical list.

## Compile and run
Open a terminal in this folder, then compile the Java file containing `main`:

```bash
javac FileName.java
java ClassName
```

If an exercise uses multiple source files, compile them together, for example:

```bash
javac Point.java Driver.java
java Driver
```

Use JDK 17 or later. For the JUnit example in Practical 14, add JUnit 5 to the project/test classpath before compiling and running the test.
