# Part A — Practice Programs (Practicals 1–14)

Each practical has its own folder. Source filenames follow the practical list where a filename was specified. Some exercises contain more than one class; compile all related `.java` files together.

**Note:** Practical 14's JUnit test is an example test source and requires JUnit 5. Practical 7's package/JAR task is supported with build/run guidance rather than a full multi-file package project.
