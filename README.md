# OOP-CEUE203-Practicals

Repository containing Object-Oriented Programming (CEUE203) practical exercises, implementations, and mini-projects in Java.

## Structure

- **`Part_A_Practice_Programs/`**: Part A practical practice programs covering concepts from Practical 01 through Practical 14.
- **`MiniBank_PartB_Practicals_01_to_14/`**: Part B MiniBank banking application implementations structured across Practicals 01 to 14.
- **`README_PART_A_AND_B.txt`**: Additional notes on project structure and requirements.

## Requirements

- **Java JDK**: JDK 17 or higher (uses records, pattern matching, modern Java features).
